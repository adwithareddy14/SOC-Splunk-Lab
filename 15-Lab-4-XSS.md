\# Page 15: Lab 4 – Detecting \& Generating Alerts on XSS Attempts



\---



\# Lab Objective



Simulate a Cross-Site Scripting (XSS) attack on DVWA and detect it in Splunk using Apache access logs.



\---



\# Environment



Ubuntu Desktop  → Victim (DVWA + Apache)



Kali Linux → Attacker



Windows Server 2019 → Splunk SIEM



\---



\# Step 1 (Ubuntu)



Start Apache



```bash

sudo systemctl start apache2

```



Checks that the web server is running.



check status too



\---



\# Step 2 (Kali)



Open Firefox



Visit



```

http://<Ubuntu-IP>/DVWA

```



Login



```

Username: admin



Password: password

```



\---



\# Step 3 (Kali)



Go to



```

DVWA Security

```



Select



```

Low

```



Click



```

Submit

```



Disables security filtering.



\---



\# Step 4 (Kali)



Open



```

XSS (Reflected)

```



\---



\# Step 5 (Kali)



Enter



```html

<script>alert('XSS')</script>

```



Click



```

Submit

```



This simulates a reflected XSS attack.



\---



\# Step 6 (Ubuntu)



View Apache logs



```bash

sudo tail -f /var/log/apache2/access.log

```



Shows the HTTP request generated by the attack.



\---



\# Step 7 (Windows Server - Splunk)



Search Apache logs



```

index=\* source="/var/log/apache2/access.log"

```



Displays Apache log events.



\---



\# Step 8 (Windows Server - Splunk)



Search for XSS



```

index=\* "/DVWA/vulnerabilities/xss\_r"

```



\---



\## Detection Query



```

index=main source="/var/log/apache2/access.log" "/DVWA/vulnerabilities/xss\_r"

```



\# Step 9 (Windows Server - Splunk)



Create Alert



```

Save As



↓



Alert

```



Configuration



```

Alert Name : XSS Detection



Trigger : Number of Results > 0



Schedule : Every 1 Minute



Severity : High

```



\---



\# Expected Result



✅ XSS payload sent from Kali



✅ Apache logs generated on Ubuntu



✅ Splunk detects the payload



✅ Alert is triggered
